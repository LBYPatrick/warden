## Intentional migration changes and corrections

- Source/branch self-update is replaced by checksum-verified binary release
  selection, as requested. Bare Warden opens the new TUI when interactive.
- Binary installation no longer installs Python, uv, a checkout, or Rosetta.
  Native ARM64 releases do not need Rosetta. Homebrew setup happens on demand
  for relevant macOS package operations, rather than every Warden install.
- Duplicate keys are merged, different local keys are preserved, and only
  selected archive modules are restored. These correct the Python behavior.
- Dry runs do not create configs or refresh APT indexes. Installed Mole uses its
  own preview; dry runs do not install missing Mole/Homebrew.
- Malformed configs are preserved; scan errors cannot silently erase package
  snapshots. Install failures return nonzero and successful entries still save.
- `--include-missing` now controls whether SSH blocks with missing keys are
  retained. Python's implementation left those blocks in place by default and
  could fail when explicitly including absent files. Go omits them by default,
  and retains their original references with the flag; it never fabricates keys.
- Missing SSH config is represented as an empty config, so a full backup remains
  usable on a machine with no SSH host definitions.
- Force now invokes reinstall/force options where available rather than only
  bypassing installed-package checks.

## Validation limits

The regression suite exercises manager/tool commands with injected process
runners and platform detection; it does not install every upstream package
manager or contact every mirror. Native compiled CLI/installer tests use an
isolated home. Cross-platform release compilation covers macOS/Linux on
ARM64/amd64; CI runs the Go suite on both macOS and Linux.
